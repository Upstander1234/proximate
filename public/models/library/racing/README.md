# Racing/track prop library — Kenney "Racing Kit" (CC0)

Full pack, sourced this session alongside `../furniture/` per the same
"download all of those, could be useful for a later thing" instruction.
Downloaded from `kenney.nl/assets/racing-kit`, version 2.0.

**License: CC0** — public domain, no attribution required (see
`LICENSE.txt`, the pack's own unmodified license file).

**All 112 models kept**, unculled — self-contained (vertex-colored, no
external texture, confirmed the same way as `../furniture/`), ~1.8 MB
total.

**Status: sourced only, NOT wired into any scene.** Most of this pack
(road tiles, pit garages, grandstands, timing/camera towers, checkered
flags, race cars) is racetrack-specific and not an obvious fit for this
game's own EMS-response driving scenes — kept anyway per the "download all"
instruction rather than pre-judged and dropped. The genuinely
general-purpose pieces most likely to get reused by a future batch:
`lightPostModern.glb`/`lightPostLarge.glb`/`lightPost_exclusive.glb`
(streetlight variants, alternatives to `../../props/light-*.glb`),
`barrierRed.glb`/`barrierWhite.glb`/`barrierWall.glb` (traffic barriers,
could complement `../../props/construction-barrier.glb`), `pylon.glb`
(a traffic cone alternative to `../../props/construction-cone.glb`), and
`fenceStraight.glb`/`fenceCurved.glb`.
