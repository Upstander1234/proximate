# Interior furniture library — Kenney "Furniture Kit" (CC0)

Full pack, sourced this session per explicit operator instruction ("all of
that stuff could be useful for a later thing — download all of those").
Downloaded from `kenney.nl/assets/furniture-kit`, version 2.0.

**License: CC0** — public domain, no attribution required (see
`LICENSE.txt`, the pack's own unmodified license file).

**All 140 models kept**, not curated down — the pack is small (~1.9 MB
total) and self-contained (vertex-colored, no external texture file needed,
confirmed by inspecting each GLB's own glTF JSON chunk: `images: []`), so
there was no real cost to keeping the full set rather than guessing in
advance which pieces a future interior-decoration batch will actually want.

**Status: sourced only, NOT wired into any scene.** Nothing in this repo's
code currently loads any file from this folder. This is a library for a
future batch — most plausibly the enterable-building station interiors the
3D mode already has (beds, sofas, kitchen/bathroom fixtures, bookcases,
lamps, tables/chairs, rugs) — not a claim that interiors are furnished
today. Two files are also directly relevant to the *outdoor* street-prop
gap flagged in `../../props/README.md`: `bench.glb` and `trashcan.glb` are
real street furniture this pack happens to include, still unplaced.

Full file list is just the pack's own filenames (`bathroomSink.glb`,
`bedDouble.glb`, `chairDesk.glb`, `kitchenFridge.glb`, `loungeSofa.glb`,
`stairsCorner.glb`, `wallWindow.glb`, etc. — 140 total) — not reproduced
here, `Get-ChildItem` lists them directly.
