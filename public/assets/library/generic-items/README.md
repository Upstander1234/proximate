# 2D icon library — Kenney "Generic Items #1" (CC0)

Sourced this session alongside `../../../models/library/furniture/` and
`../../../models/library/racing/`, same "download all, could be useful
later" instruction. Downloaded from `kenney.nl/assets/generic-items`.

**License: CC0** — public domain, no attribution required (see
`LICENSE.txt`, the pack's own unmodified license file).

326 flat PNG icon sprites (everyday objects/tools/household items, in both
a "Colored" and a "White" variant set), ~0.4 MB total, kept in full.

**Status: 3 icons now wired in.** `genericItem_color_102.png` (a first-aid
kit box), `_142.png` (a rolling case), and `_145.png` (a briefcase) replace
three of `EQUIPMENT_ART`'s flat placeholder icons (`drug_bag`/`trauma_bag`/
`airway_bag` — see `src/assets/equipment/README.md` and
`scripts/build_equipment_icons_from_cc0.py`) — found by building a labeled
163-icon contact-sheet montage and checking candidates directly, the only
3 of the 163 that are genuine, non-forced equipment-adjacent matches in
what is otherwise a generic household/tools/electronics icon set. The
other 160 icons remain unused. Plausible future use for the rest: HUD/
inventory icons, a loadout/bag-contents display, or Sandbox/settings UI
iconography — none of that exists yet.
