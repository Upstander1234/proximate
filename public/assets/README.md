# Proximate asset pipeline

Everything in this folder is a **placeholder**, generated by
`scripts/generate_placeholders.py`. Every placeholder is a labeled, tinted
rectangle sized correctly for where it's used, so you can see exactly what
needs art and at what dimensions.

## How to replace a placeholder

1. Find the file (see the map below, or just search this folder for the name
   you saw in-game — the label on every placeholder matches its filename).
2. Drop your finished art in with the **exact same filename and extension**.
3. Done. Nothing in the code needs to change — `src/assets.js` is the only
   place that knows these paths, and it already points here.

Keep the same pixel dimensions the placeholder used (noted in the corner of
each placeholder image) or as close as practical — some are full-bleed
backgrounds, others are composited UI chrome, and wildly different aspect
ratios may not lay out correctly.

## Folder map

| Folder | Contents | Typical size |
|---|---|---|
| `backgrounds/` | Station rooms, city map, exterior | 1920×1080 |
| `backgrounds/overlays/` | Night/weather overlays composited on top of a background | 1920×1080 |
| `weather/` | Standalone weather effect art (rain/snow/fog/smoke/night) | 1920×1080 |
| `characters/portraits/` | Base character portraits, `{role}_{gender}_{variant}.png` | 512×512 |
| `characters/expressions/` | Shared facial-expression overlays, reused by every character | 256×256 |
| `characters/poses/` | Shared pose/stance overlays, reused by every character | 384×384 |
| `vehicles/` | One image per vehicle kind | 640×400 |
| `equipment/` | Gear/kit icons | 256×256 |
| `emergencies/` | Full-scene emergency illustrations | 1280×720 |
| `events/` | Story/event illustrations (promotions, arguments, etc.) | 1280×720 |
| `ui/` | Dialogue boxes, frames, buttons, and other chrome | 512×256 |
| `icons/` | Small gameplay resource/stat icons | 128×128 |
| `achievements/` | Achievement badge art | 320×320 |
| `audio/` | Short placeholder tones — swap for real SFX/music, any filename kept | — |
| `placeholders/` | Generic fallbacks (missing portrait, loading spinner, logos) | varies |

## Characters: portraits + expressions + poses, not one image per combo

A character is composed from **three layers**, not one flat image per
mood/pose:

```
characters/portraits/captain_male_01.png   ← base body/head
characters/expressions/concerned.png       ← swapped in over the face
characters/poses/holding_radio.png         ← swapped in for the stance/hands
```

This keeps the asset count sane — 18 roles × 2 genders × 4 variants for
portraits, plus 10 expressions and 11 poses *shared by every character*,
instead of thousands of one-off combination images. `src/assets.js` exports
`portraitPath()`, `expressionPath()`, and `posePath()` for exactly this.

Each role/gender has 4 numbered variant slots (`_01` through `_04`) so the
same crew list doesn't look identical — use those slots for different looks,
skin tones, builds, etc. `variantFor()` in `src/assets.js` deterministically
picks a variant per person (hashed off their name/id), so a given NPC always
renders with the same face across a session.

## Adding a brand-new asset

1. Add the key to the relevant list in `scripts/generate_placeholders.py`.
2. Add the matching path/export to `src/assets.js`.
3. Run `python3 scripts/generate_placeholders.py` — it only creates files
   that don't exist yet, so it's safe to re-run any time.

## Regenerating everything from scratch

`python3 scripts/generate_placeholders.py --force` — only do this if you
want to wipe hand-placed art and go back to placeholders; it will overwrite
everything.
