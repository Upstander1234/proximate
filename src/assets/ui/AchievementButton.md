# AchievementButton

## Purpose
A persistent button on the main game interface (alongside the Settings gear)
that opens the Achievements screen.

## Intended appearance
A small icon button matching the Settings gear's size and treatment: a rosette /
medal / trophy glyph in a thin-bordered pill, fixed near the Settings control.

## Theme / style
Identical framing to the Settings button (rgba dark fill, hairline border, mono).
Neutral by default; a subtle accent/badge when a new achievement is unlocked.

## Important visual elements
- Trophy/medal glyph, legible at ~16px.
- Optional unread-count badge for newly earned achievements.

## Notes for the artist / asset generator
Must sit comfortably next to the ⚙ gear without crowding it. Keep the "new"
badge quiet — a small dot, not a loud number, unless count > 1.
