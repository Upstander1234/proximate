# AchievementScreen

## Purpose
The full screen listing earned and locked achievements, reachable from the
Achievement button. Available in both Learning Modes.

## Intended appearance
A scrollable grid or list of achievement rows. Earned entries are full-color with
title, description, and date earned; locked entries are dimmed with a lock glyph
and a hint (or a hidden description for secret ones).

## Theme / style
Dark UI, hairline dividers, mono section labels. Earned = accent color + subtle
glow; locked = desaturated. Categories/sections optional (e.g., Clinical,
Career, Milestones).

## Important visual elements
- Achievement rows: icon, title, description, earned/locked state, date.
- Clear earned-vs-locked contrast.
- Progress summary at top (e.g., "12 / 40 unlocked").

## Notes for the artist / asset generator
Design for a growing list — layout must scale to many achievements. Keep locked
entries readable but clearly secondary. No spoilers for secret achievements.
