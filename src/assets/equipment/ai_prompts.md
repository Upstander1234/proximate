# AI-generation prompts — EQUIPMENT_ART (all 18 icons)

**Why this file exists, and why this list is longer than a prior pass
claimed.** Kenney's "Generic Items #1" pack was previously used for 3/18
(`drug_bag`/`trauma_bag`/`airway_bag`) and counted as "real, done." A
direct visual re-check found that framing was wrong: `trauma_bag` reads as
a wheeled travel suitcase (rolling handle, caster wheel — nothing reads as
medical), and `airway_bag` reads as a generic dark briefcase indistinguishable
from a laptop case. Neither communicates what it's supposed to be. Only
`drug_bag` (an orange box, blue medical cross) is legible, and even that's
a generic household first-aid-kit icon, not real EMS gear. **All 18 are
placeholder now, not 15** — no CC0 flat medical-equipment icon pack exists
anywhere in this project's library or in a fresh search (Flaticon-style
results are CC-BY/paid, not CC0; Kenney's own catalog has no medical pack).
These prompts are for a human to run through an image generator.

**No real reference image exists for this category** — the previous "3
already real" reference table is removed for the reason above; don't use
the old `drug_bag`/`trauma_bag`/`airway_bag` files (still on disk at their
existing paths) as a style or accuracy reference. Rely on the written
style anchor below.

**Shared style anchor — paste this before every prompt below**:

> Flat-shaded icon illustration of a single piece of EMS/medical
> equipment, centered, 1:1 square framing, thin consistent linework, a
> small blue or amber accent-color highlight rather than full-color
> realism, plain transparent background, no text, no shadow, no
> environment.

Save each result to `public/assets/equipment/{key}.png` (matching
`EQUIPMENT_ART` in `src/assets.js`).

## `drug_bag` (REPLACES a weak existing file — see the correction above)
> [style anchor] + A soft-sided EMS drug/medication bag, open flap
> showing labeled compartments with a few small drug vials/ampoules
> visible inside, a red cross or star-of-life patch on the front — should
> read unambiguously as MEDICATION storage, not a generic first-aid box.

## `trauma_bag` (REPLACES a weak existing file — see the correction above)
> [style anchor] + A boxy soft-sided EMS trauma bag with multiple external
> pouches/pockets and a shoulder strap, gauze roll or trauma shears
> visible tucked in a side pocket — should NOT have wheels or a rolling
> handle (the existing file wrongly reads as travel luggage; this is a
> carried/slung bag).

## `airway_bag` (REPLACES a weak existing file — see the correction above)
> [style anchor] + A soft-sided EMS airway bag, open or semi-open showing
> an oxygen mask, an oral airway, and BVM tubing peeking out the top —
> should read clearly as AIRWAY equipment, not a generic dark briefcase
> (the existing file's flaw).
