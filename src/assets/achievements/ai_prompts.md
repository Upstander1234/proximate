# AI-generation prompts — ACHIEVEMENT_ART (9 badges)

**Why this file exists.** No CC0 pack in this project's library has a
circular "enamel-pin badge" achievement-icon set (Kenney's game-icons
packs are flat UI glyphs, not badge frames; a search this pass found only
CC-BY/paid badge packs). These prompts are for a human to run through an
image generator.

**No real reference image exists for this category yet** — unlike the
other `ai_prompts.md` files in this project, nothing in the repo has the
circular enamel-pin badge frame this brief describes (the closest visual
precedent, the flat-glyph icons at `public/assets/icons/`, is a
DIFFERENT, flatter style — don't use those as a literal reference, they're
linked from `src/assets/icons/ai_prompts.md` for that category only).
Rely on the written style anchor below.

**Shared style anchor — paste this before every prompt below**, so the
grayscale/locked CSS filter this project already applies works cleanly
(same badge silhouette, only the glyph differs):

> Digital illustration of a circular achievement badge, enamel-pin/metal-
> medallion style, warm gold/bronze metallic rim, flat colored center disc,
> a single bold simple glyph centered on the disc, clean vector-style
> shapes (no fine detail that would disappear at small size), plain
> transparent background, no text, no ribbon, no drop shadow. Square 1:1
> canvas, badge filling most of the frame.

Save each result to `public/assets/achievements/{id}.png` (matching
`ACHIEVEMENT_ART` in `src/assets.js`).
